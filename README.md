**Technical Formative Assessment 3**

> Extension of POS system from TFA2

**Added Features:**

1. Add a New Customer form (/customers/new) that validates required fields (full
name required, email required and valid) before inserting a record.

2. Add a New User form (/users/new) that validates required fields (username
required and unique, full name required) before inserting a record.

3. Add edit pages for both customer and user accounts that pre-fill the form with the
existing record's data and update it on submit.

4. Add an avatar column to the users table. On the user edit form, add a file input for a profile picture; validate that the
uploaded file is a JPG or PNG no larger than 2MB, prepare a display-ready copy or thumbnail, store it in a public
uploads folder, and save only the filename in the avatar column.

5. Display each user's prepared avatar or thumbnail on the User Accounts listing page (fall back to a placeholder image if
none was uploaded).
